<h1>Description</h1>

This is an application to help Sam with scheduling tutors and generating schedule information

<h1>Build Instructions</h1>

The dlls included in this project have been compiled with g++. The project can be compiled and linked with g++ by running <i>build/_build.bat</i>.

To build with visual studio, you need to download [RmlUi's binaries](https://github.com/mikke89/RmlUi/releases/tag/6.2) or build them yourself.

In the future, we should probably use cmake.
